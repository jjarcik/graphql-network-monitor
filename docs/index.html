Privacy Policy

GraphQL Network Monitor (Chrome extension) · Last updated: October 20, 2026

Summary

GraphQL Network Monitor is a developer tool. It shows the network requests of the page you are inspecting inside Chrome DevTools. All data stays in your browser. The extension has no server, does not send data anywhere, does not use analytics and does not sell or share any information.

What the extension accesses

Only while its DevTools panel is open, the extension reads the following data of the inspected tab:

  • URLs, methods, status codes and timing of fetch/XHR requests;
  • request and response headers, which may include cookies and authorization tokens;
  • request bodies (for example GraphQL queries and variables) and response bodies.

This data is needed for the single purpose of the extension: displaying network traffic to the developer who opened the panel.

How the data is used and stored

  • Captured requests are kept only in the memory of the DevTools panel and are discarded when the panel or DevTools is closed.
  • The extension stores a few UI preferences (selected tab, panel split, "Preserve log") in the panel's local storage. These contain no request data.
  • Data is copied to your clipboard only when you click a "Copy" button.
  • Nothing is transmitted to the author or to any third party.

Permissions

  • webRequest – detect in-flight requests and read their headers for the inspected tab.
  • scripting – while the panel is open, inject a small script into the inspected site that observes fetch/XHR responses. Other tabs and sites are not affected.
  • Access to all sites – developers inspect arbitrary websites, so the extension cannot know the hosts in advance.

Children

The extension is a developer tool and is not directed at children.
